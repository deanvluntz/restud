1. SAMPLE START, GROSS INFLOWS, ARDL CITATION
======================================================================
ASKED: Should the sample start in 1975? The code still says the DR data start in
1979. What is the case against gross inflows in the fiscal model? Add the ARDL
package citation.
ANSWER / DONE:
- 1977 is the earliest possible start. L_ln_debt_gdp (the annual log change in
  debt/GDP, lagged) needs debt/GDP for 1975 and 1976, and the HPFD debt series
  starts in 1974-75. A 1976 start works only if the debt control is dropped
  (coefficient 0.0063). sample_start_1977.R was written to show this.
- Against gross inflows: the scaled rate matches the model's per-worker fiscal
  logic and removes the mechanical effect of population growth. The AIC gap
  (1.2) is not meaningful, an encompassing test rejects neither form, and the
  projection coefficient is the same. Gross inflows stay a robustness check.
- Added Natsiopoulos, Tzeremes and Finnan (2026), R package ARDL v0.2.5, to both
  reference lists and wherever the bounds test is described.
